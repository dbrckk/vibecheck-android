# VibeCheck 1.2.1 (versionCode 5)

## en-US
Production reliability update. Local game data is now explicitly excluded from Android cloud backup and device-transfer backup rules. Store disclosures were aligned with the public-figure Solo Party experience, release validation was strengthened, and navigation icon compatibility was improved.

## fr-FR
Mise à jour de fiabilité pour la production. Les données locales du jeu sont désormais explicitement exclues des règles Android de sauvegarde cloud et de transfert d’appareil. Les mentions Store ont été alignées avec Solo Party et ses personnalités publiques simulées, la validation de release a été renforcée et la compatibilité des icônes de navigation a été améliorée.
