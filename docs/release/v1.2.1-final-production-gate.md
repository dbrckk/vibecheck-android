# VibeCheck 1.2.1 — final production gate

## Audited source
- Package: `com.dbrckk.vibecheck`
- Release: `1.2.1` (`versionCode 5`)
- Android: minSdk 24, targetSdk 36
- No INTERNET permission; offline-first
- No ads, billing, or analytics runtime dependency
- Play App Signing upload-key reset metadata is stored in `docs/release/v1.2.0-play-key-reset.md`

## Issues fixed in the final pass
1. **Know Me handoff**: a guess could be accepted before the private pass-phone screen was confirmed, allowing incorrect scoring on repeated input. The ViewModel now rejects guesses while the handoff is pending, and a regression test covers repeated submissions.
2. **Solo nickname editing**: trimming every edit made it impossible to type a space or clear the field naturally. Input is preserved while editing; `GameViewModel.startSoloSession` still normalizes the nickname before use.
