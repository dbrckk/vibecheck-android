# VibeCheck 1.2.1 production audit

Date: 2026-11-05

## Release identity
- applicationId: `com.dbrckk.vibecheck`
- versionName: `1.2.1`
- versionCode: `5`
- compileSdk / targetSdk: `36`
- minSdk: `24`

## Production strengths
- Offline-first; no account required.
- No manifest runtime permissions.
- No INTERNET permission in the app manifest.
- Cleartext traffic disabled.
- App backup disabled and explicit backup/device-transfer exclusions configured.
- Non-exported FileProvider restricted to `cache/shared_results/`.
- Challenge URI parsing rejects wrong scheme/host/path, fragments, duplicate query keys, oversized links and invalid enum/range values.
- Solo public-figure simulations are disclosed in setup, gameplay, result/share copy and Store listing.
- No ads, analytics or billing dependency is expected in the release runtime.
- R8 and resource shrinking enabled.
- targetSdk 36 satisfies the Google Play Android 16 target requirement for app updates.

## Fixes applied by this audit
- Bumped release to 1.2.1 / versionCode 5 so the hardened artifact is unambiguous.
- Added Android 12+ data extraction rules and legacy backup exclusions.
- Updated Play listing wording so it no longer describes public-figure simulations as generic fictional characters.
- Added an in-app Settings entry to the publicly deployed privacy policy and a direct privacy inquiry link.
- Updated privacy copy to match public-only simulations and backup behavior.
- Replaced deprecated directional icons with RTL-aware AutoMirrored icons.
- Fixed leaderboard ordering so the actual wins/score leader is ranked first and made the list scroll-safe.
- Made onboarding and pass-phone handoff scroll-safe for small displays and larger text.
- Updated GitHub Actions to current Node 24-capable action generations.
- Changed lint gate from debug lint to release lint.
- Added a release-runtime dependency audit that rejects ads, Firebase Analytics or Billing SDKs.
- Added CI verification of 16 KB ELF LOAD-segment alignment for 64-bit native libraries bundled transitively by AndroidX.
- Refreshed project-state and Play release documentation.

## Not fully verifiable in source CI
- Physical-device behavior and OEM-specific rendering.
- Play Console Data Safety answers and content-rating answers.
- Play pre-launch report.
- Google Play review outcome.
- Verified HTTPS App Links; the current custom challenge URI remains intentionally supported until a controlled domain/certificate association is available.

## Release decision
Source is eligible for a production candidate only after the exact release branch and merged main CI are green. The signed AAB must then be verified and tested through a Google Play test track before production rollout.
